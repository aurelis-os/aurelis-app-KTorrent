# KTorrent

KTorrent is a BitTorrent client for KDE. It provides a user-friendly interface for downloading and managing torrent files, with features like bandwidth scheduling, IP filtering, protocol encryption, and support for magnet links.

This is an **Aurelis Linux** package, but it can also run as a regular AppImage on any Linux distribution.
